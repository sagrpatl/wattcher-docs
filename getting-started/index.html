Getting started

Guide › Getting started

Download Wattcher from the Releases page and install it like any other app. Prefer to build it yourself? See Build from source in the README.

Install on a Mac

Section titled “Install on a Mac”

macOS 11 or newer.

  1. Download Wattcher_version.dmg, open it and drag Wattcher into Applications.
  2. Open Wattcher from Applications. The first time, macOS stops it: “Wattcher” Not Opened (“Apple could not verify…”). Press Done, not Move to Trash.
  3. Open System Settings → Privacy & Security, scroll down to “Wattcher was blocked to protect your Mac” and press Open Anyway, then confirm with your password or Touch ID. Wattcher opens, and from now on it opens normally.

Why the warning? Wattcher isn’t registered with Apple (that costs a yearly fee), so macOS can’t check who made it. Wattcher is open source: anyone can read what it does.

If macOS instead says “Wattcher” is damaged and can’t be opened, it isn’t damaged: run this once in Terminal, then open Wattcher again:

Updating: quit Wattcher, download the new version and drag it into Applications, replacing the old one; then Open Anyway once more. Your settings, devices, workouts and rides are kept.

Install on Linux

Section titled “Install on Linux”

Two downloads, both for x86_64 and arm64 PCs:

  • Flatpak (recommended): sandboxed, works on any desktop distro, including Bazzite, SteamOS and Silverblue, and gives you a launcher entry, so the keyboard shortcuts work.
  • AppImage: one file you run directly, for distros without Flatpak.

Flatpak

Section titled “Flatpak”

Download Wattcher-version-x86_64.flatpak (or aarch64 on an ARM PC) and install it by double-clicking it (KDE Discover or GNOME Software), or in a terminal:

Start Wattcher from your app launcher. Update by installing the new file the same way. Remove it with flatpak uninstall dev.trainer_overlay.TrainerOverlay (your workouts and rides stay in Documents).

The AppImage has no launcher entry, so on Wayland the keyboard shortcuts don’t work (they need one: see Linux notes). Use the Flatpak if you want them. If it complains about FUSE, run it with --appimage-extract-and-run.

First launch

Section titled “First launch”

Wattcher opens two things: the Control window and, at the top left of the screen, the overlay in move mode (“DRAG TO MOVE” under the card): drag it where you want it, then lock it with Ctrl+Shift+H (or Lock overlay on the Ride tab).

The Control window has seven tabs: Library (your workouts), Builder (write a workout), Ride (start, pause, who controls the trainer), Rides (saved rides), Devices (trainer and sensors), Overlay (widgets and presets) and Settings. Closing the window only hides it: the overlay keeps running. Bring it back from the Dock or the bicycle icon in the menu bar. Quit with the Quit button, the menu-bar icon or Ctrl+Shift+Q.

On first launch, Wattcher asks for your FTP and weight at the top of the window: every workout target is a percentage of your FTP. You can change them any time in Settings → Rider. Weight is used for the speed and distance estimate, max heart rate for the heart-rate cap suggestion.

What macOS asks for

Section titled “What macOS asks for”
Prompt When Choose
Bluetooth (“Wattcher would like to use Bluetooth”) first launch Allow: needed for the trainer and sensors
Local Network (“…find and connect to devices on your local network”) first launch Allow if you’ll use mirroring or the phone remote; fine to deny otherwise
Accept incoming network connections (only if the macOS firewall is on) first launch Allow for the phone remote and mirroring

Wattcher doesn’t need Accessibility or Screen Recording: the keyboard shortcuts and the overlay work without them.

Because Wattcher isn’t registered with Apple, macOS may ask for Bluetooth or Local Network again after an update: allow it again. Missed a prompt? System Settings → Privacy & Security → Bluetooth / Local Network → turn on Wattcher, and System Settings → Network → Firewall → Options for incoming connections.

Where things are kept

Section titled “Where things are kept”
What macOS Linux
Workouts ~/Documents/TrainerOverlay/Workouts same
Rides (.fit) ~/Documents/TrainerOverlay/Rides same
Settings, devices, ride journals, ride logs ~/Library/Application Support/dev.trainer-overlay.app Flatpak: ~/.var/app/dev.trainer_overlay.TrainerOverlay/data/dev.trainer-overlay.app; AppImage: ~/.local/share/dev.trainer-overlay.app

(The folder names come from Wattcher’s earlier name, Trainer Overlay.) Settings → Recording → Open rides folder and Library → Open workouts folder open them.

Linux notes

Section titled “Linux notes”
  • Overlay: on KDE Plasma 6, Sway, Hyprland and other wlr-layer-shell desktops the overlay is drawn on the desktop’s overlay layer, above fullscreen video and borderless games. GNOME has no layer shell: the overlay is a normal always-on-top window there, so use windowed or maximized video. If the overlay doesn’t show up, Settings → Overlay → Overlay mode → XWayland, then restart Wattcher.
  • Keyboard shortcuts go through the desktop’s Global Shortcuts portal. The first launch asks once: on KDE a “Global Shortcuts Requested” dialog lists the Ctrl+Shift shortcuts; press OK. Change them later in System Settings → Keyboard → Shortcuts → Wattcher. This needs Wattcher’s launcher entry, which the Flatpak installs: start Wattcher from the launcher.
  • Bluetooth uses BlueZ: just have Bluetooth on, no permission prompt.
  • NVIDIA: Wattcher sets WEBKIT_DMABUF_RENDERER_FORCE_SHM=1 by itself. Don’t set WEBKIT_DISABLE_DMABUF_RENDERER=1: it leaves the overlay half drawn.
  • Firewall (for the phone remote and mirroring): see Troubleshooting.
