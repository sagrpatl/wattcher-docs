Building workouts

Guide › Building workouts

The Builder tab writes workouts as plain text in the intervals.icu workout builder format, so you can paste workouts between intervals.icu and Wattcher. The profile and the estimates (duration, TSS, IF, work, NP) update as you type.

Write one

Section titled “Write one”
  1. Control window → Builder. It starts with an example; New clears it.
  2. Give it a Name (and a description if you like).
  3. Type the steps (below). Errors are underlined with the line and what’s wrong; the preview keeps the last valid version.
  4. Save puts it in your Workouts folder as a .txt file (tick also export .zwo for a Zwift copy). Save & Ride saves it and selects it on the Ride tab.

Edit on a Library workout opens it in the Builder, also .zwo, .erg and .mrc files: saving writes a new .txt workout and leaves the original alone.

The format in five lines

Section titled “The format in five lines”
  • A step is a line starting with -: a duration and a target, optionally a cadence and a cue text (Settle in shows on the overlay during that step).
  • Durations: 10m, 30s, 1h, 1m30, 5'30".
  • Targets: 75% of FTP, 200W, zones Z2, ranges 88-92% (ridden at the midpoint), ramp 50-75% (a slope), freeride (no target: ERG off; add gear 18 to start it in a virtual gear, or resistance 40% for an exact level).
  • A section header (Warmup, Main Set 3x) names the steps below it; 3x repeats them. Leave a blank line before and after a repeat block.
  • # name: … and # description: … lines set the workout’s name and description in a file.

The Builder’s Syntax help has a summary, and Workout text format is the full reference (timed cues, intensity tags, what isn’t supported and why).

Other workout files

Section titled “Other workout files”

Put .zwo (Zwift), .erg / .mrc (TrainerRoad, Golden Cheetah and others) or .txt files in the Workouts folder, or use Library → Import workout…. Library → Refresh picks up files you added while Wattcher was open. A file that can’t be read is listed with the reason.
