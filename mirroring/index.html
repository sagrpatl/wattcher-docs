Mirroring

Guide › Mirroring

Show your ride live on a second computer. One computer, the host, talks to the trainer and runs the ride. Other computers running Wattcher, the mirrors, show the same ride as it happens, each with its own overlay. A phone remote, if you use one, controls the host.

When to use it

Section titled “When to use it”
  • Ride with a game or a film on the TV. The laptop by the bike is the host; the gaming PC on the TV mirrors it, so your power, target and interval float over the game without that PC ever touching the trainer.
  • A big screen and a small one. Keep a full-detail overlay on the laptop and a few big numbers on the TV across the room. Each computer has its own preset.
  • The trainer is easier to reach from one computer. Bluetooth range or a better Bluetooth adapter decides the host; you can still watch on the other.

Mirroring doesn’t send any controls. To pause, skip or change the target from the saddle, use the phone remote or the host’s keyboard shortcuts.

Any computer can be the host or a mirror; it depends only on which one rides. A host can have up to 4 mirrors at once.

Pair once

Section titled “Pair once”
  1. On the host (the computer by the bike): Settings → Phone & mirroring → turn on Let my other computers mirror rides. It’s off by default.
  2. On the mirror (the computer that should show the ride): Settings → Phone & mirroring → “Mirror another computer’s rides” lists the computers running Wattcher on your network. Press Mirror its rides… next to the host. The mirror shows a 4-digit code: “check it shows code 4821”.
  3. On the host, answer “Allow name to mirror your rides? Only if it shows code 4821”: on the overlay (Allow / Deny), in the Control window, or on the phone remote’s More tab. Allow only if the code matches the one on the mirror’s screen; otherwise press Deny. Nothing pops up over a game and nothing takes focus. The request expires after 2 minutes.
  4. Done. Both computers remember the pairing. From now on, whenever the host starts a ride and Wattcher is open on the mirror, the mirror shows it by itself.

While mirroring

Section titled “While mirroring”
  • The mirror is view only. Control the ride on the host (its overlay, its keyboard shortcuts, or a phone connected to the host). A phone connected to the mirror can still arrange the mirror’s overlay, but not control the ride. The mirror’s card has no control bar; a small “⧉ host” tag says whose ride it is.
  • The mirror pauses its own Bluetooth (it never touches the trainer) and can’t start a ride of its own. Its Control window says “Mirroring host”, with Stop mirroring on the Ride tab.
  • Only the host records the ride (one .fit file). The summary shows on both for 30 seconds after the ride, then the mirror goes back to normal.
  • Each computer keeps its own overlay layout: preset, widgets, positions and sizes. The TV can use Big screen while the laptop uses Training. Change the mirror’s layout on the mirror as usual; starting or stopping mirroring never moves anything.
  • Beeps play on both computers, each at its own volume.
  • If the host disappears, the mirror shows “Lost connection to host · retrying” and hides its overlay after a minute.

Settings

Section titled “Settings”

Settings → Phone & mirroring:

  • Let my other computers mirror rides (off by default): this computer can be found on the network and accept pair requests. Turn it off to stop both. Computers that mirror this one keep their pairing, and work again when you turn it back on.
  • Computers allowed to mirror this one are listed with Revoke (it’s disconnected within 2 seconds and would have to ask again).
  • Computers this one mirrors are listed with Remove.
  • “This computer shows up as name”: the computer’s name. On the network it shows up shorter (“Alex’s MacBook Pro” as “MacBook Pro”); only a computer you allowed learns the full name.
  • Only one pair request shows at a time. If another computer asks meanwhile, it’s told the host is busy; after a Deny, that computer has to wait a minute before asking again.

Network

Section titled “Network”

The computers find each other with Bonjour / mDNS and talk over the same port as the phone remote (8787 by default).

  • macOS: allow Wattcher when asked about Local Network access and incoming connections (System Settings → Privacy & Security → Local Network, and Network → Firewall).
  • Linux with a firewall: sudo firewall-cmd --add-service=mdns --add-port=8787/tcp (add --permanent to keep it after a reboot). Fedora’s and Bazzite’s default desktop zone already allows it.
  • It’s plain http on your home network, like the phone remote: someone on your network could read the ride data a mirror receives, but mirrors can’t change anything. A computer pretending to be your host can’t get the mirror’s pairing secret or show a fake ride on it.
